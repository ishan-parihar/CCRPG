# Somatic / Orange — Deterministic Game Concept

> **Axis:** Objective psychomotor measurement — reaction time, rhythm accuracy, sequence precision, coordination metrics.  **Why this axis for this module:** Orange somatic mastery is defined by measurable technique; deterministic scoring captures the body's rational precision without subjective interpretation.

---

## 1. Game Identity

- **Title:** Kinetic Calibration Lab
- **Core Mechanic:** Multi-domain motor sequences scored on timing precision, coordination accuracy, and adaptive rhythm-matching. Player executes increasingly complex physical patterns against objective benchmarks.
- **Duration:** 4–8 minutes per session, infinite checkpoint.
- **Internal Progression:** Single-limb timing → cross-limb coordination → multi-domain sequences → variable-rhythm adaptation → fatigue-managed precision under load.

## 2. Catalyst Delivery

- **Unique Presentation:** A biomechanics laboratory where the player's avatar is a precision instrument being calibrated. Each trial is framed as "tuning" a physical system.
- **Differs From Others:** Pure measurement — no narrative, no choice, no language. The body's objective capacity speaks for itself.
- **Uniquely Surfaces:** DA (obsessive metric improvement, ignoring fatigue signals) and DAll (avoidance of precision challenges, settling for "good enough" Amber-level repetition).
- **Successful Integration:** Player achieves high precision AND self-regulates effort, voluntarily resting before breakdown, maintaining felt-sense contact during execution.

## 3. Game Design

- **Setup:** Calibration interface presents target patterns. Player sees timing windows, coordination targets, rhythm signatures.
- **Interaction Phases:**
  1. Baseline — simple reaction time and single-pattern execution
  2. Complexity — multi-step sequences requiring motor planning
  3. Variability — rhythms shift unpredictably, demanding adaptation
  4. Load — fatigue accumulates, precision must be maintained through rational pacing
  5. Integration — player chooses when to push and when to recover within the trial
- **Feedback Examples:**
  1. Timing deviation displayed as millisecond variance (objective, non-judgmental)
  2. Coordination score shows cross-limb synchronization percentage
  3. Fatigue curve overlaid on precision curve — reveals dissociation patterns
  4. Recovery efficiency metric — how quickly precision returns after rest
  5. Technique consistency across domains — transfer score
- **Difficulty Adaptation:** Sequence complexity scales with demonstrated precision. Fatigue pressure increases when player shows DA patterns (ignoring rest). Simplifies when DAll patterns emerge (avoidance of challenge).
- **Internal Progression Table:**

| Level | Challenge | Shadow Probe |
|---|---|---|
| 1–3 | Single-domain timing | Baseline capacity |
| 4–6 | Cross-domain coordination | DA: metric obsession emerges |
| 7–9 | Variable rhythm under fatigue | DA: dissociation from pain signals |
| 10–12 | Self-paced precision management | DAll: avoidance of mastery challenge |
| 13+ | Full integration: precision + felt-sense | All shadows converging |

## 5. Technical Requirements

- **Input Types:** Tap timing (touch/click), hold duration, swipe direction and speed, multi-touch coordination, rhythm input, pressure sensitivity (where available).
- **Timing:** Millisecond-precision input capture. Frame-accurate feedback. Latency compensation for device variance.
- **NPC/AI:** Adaptive difficulty engine adjusts sequence complexity in real-time. Fatigue model tracks cumulative load and recovery.
- **LLM:** Not primary. Used only for post-session insight generation if player requests performance narrative.
- **State Persistence:** Per-trial precision scores, fatigue curves, recovery patterns, cross-session improvement trajectories, shadow-indicator time-series, drive-health ratios per session.
