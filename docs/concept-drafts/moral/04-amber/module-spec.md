# Moral / Amber — Module Specification

> **Line:** Moral  **Stage:** Amber / Mythic-Membership  **Vibration:** The felt rightness of the code — morality as internalised law that binds self to group through genuine guilt and sacred duty.

---

## 1. Capacity Definition

Conventional morality: the capacity to internalise a moral code as intrinsically right (not merely fear of punishment), experience genuine guilt upon violation, maintain vows across time, and orient moral reasoning around group-loyalty and duty. The code IS right because it is the code. Morality = rule-following from principle, not consequence.

**Prerequisite capacities (Red/Magenta moral):** consequence-logic, taboo-sensing, ritual-reciprocity.
**Emergent capacities (Orange moral):** universal principles, contextual ethics, post-conventional reasoning.

## 2. Shadow Archetypes

### 2.1 Dark-Addiction: The Fundamentalist
Rigid rule-worship. Cannot tolerate moral ambiguity. Enforces the code absolutely — every deviation is sin. Collapses all moral complexity into binary right/wrong. The code becomes a weapon rather than a guide. Guilt is weaponised against self and others.

### 2.2 Dark-Allergy: The Amoral
Refuses conventional morality entirely. Remains in Red consequence-logic — no guilt, no internalised rules. Views morality as social control. Cannot form genuine moral commitments. "Rules are for the weak."

### 2.3 Golden-Addiction: The Premature Ethicist
Performs post-conventional morality (Orange universal principles, Green contextual ethics) without genuine conventional foundation. Speaks the language of nuance but has never truly submitted to a code. Moral reasoning is sophisticated but ungrounded — collapses under pressure.

### 2.4 Golden-Allergy: The Unquestioning
Conventional morality is present and functional but refuses all moral examination. "The code is right because it is the code — don't question it." Healthy rule-following becomes calcified. Cannot evolve toward principled reasoning because examination itself feels like betrayal.

## 4. Healing Vectors

### 4.1 Heal/Evolve (Agape + Agency → Dark Shadows)
**DA:** Agency reclaims sovereignty FROM the code — "I follow because I choose, not because I must." Agape returns compassion to those who deviate.
**DAll:** Agency commits to a code voluntarily. Agape returns to the group-moral-body, allowing guilt to arise naturally.

### 4.2 Evolve/Heal (Eros + Communion → Golden Shadows)
**GA:** Communion grounds the ethicist in actual moral community — submit to a code before transcending it. Eros reaches toward genuine depth rather than performed sophistication.
**GAll:** Eros reaches toward moral examination as growth, not betrayal. Communion shares moral questioning with trusted others.

### 4.3 Integration Criteria
- Can follow a code AND question it without collapse
- Genuine guilt arises naturally (not weaponised, not absent)
- Vows are kept across time without rigidity
- Group-loyalty is felt without exclusion of the deviant

## 6. Compound Shadows & Cross-Module Relationships

### 6.1 The Dogmatic Enforcer (Moral × Interpersonal, both DA)
Rigid morality fused with rigid group-enforcement. The code is absolute AND must be imposed on all others. Interpersonal capacity becomes moral policing. Resolution: Agency in both lines — moral sovereignty + relational sovereignty.

### 6.2 The Guilt-Machine (Moral × Emotional, both DA)
Rigid morality fused with constant guilt-affect. Every micro-deviation triggers crushing self-punishment. Emotional capacity becomes guilt-amplifier. Resolution: Agape in both lines — compassion toward self + compassion toward moral imperfection.

### 6.3 The Moral Coward (Moral × Willpower, both DAll)
No internalised moral code + no sustained commitment = amoral impulsivity. Cannot form vows because no moral ground AND no willpower to maintain them. Resolution: Agency in both lines — commit to something, anything, and hold it.

### 6.4 The Virtue-Signaller (Moral × Emotional, both GA)
Performed post-conventional ethics + performed emotional sophistication. Looks morally and emotionally advanced but neither is grounded. Resolution: Communion in both lines — genuine moral community + genuine emotional intimacy expose the performance.

## 7. Shadow Surfacing Sequence

### 7.1 Progressive Revelation
Phase 1 (sessions 1-3): Present clear moral codes — observe compliance patterns, guilt-response latency, vow-formation.
Phase 2 (sessions 4-7): Introduce moral ambiguity — observe rigidity (DA), dismissal (DAll), premature sophistication (GA), refusal to engage (GAll).
Phase 3 (sessions 8+): Cross-validate shadow hypotheses across modalities.
