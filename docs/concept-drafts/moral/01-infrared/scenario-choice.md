# Moral × Infrared — Scenario-Choice

## 1. Game Identity

| Field | Value |
|---|---|
| Modality | Scenario-Choice |
| Unique lateral | Harm-based choices — approach safe / avoid harmful based on sensation |
| Core mechanic | Binary approach/avoid decisions driven by sensory harm-cues |
| Session length | 60–120 seconds per checkpoint |
| Infinite checkpoint | Yes — each scenario set is a checkpoint |

## 2. Catalyst Design

### 2.1 Surface Experience

The player's creature stands at a fork. Each path radiates sensory cues — one path glows warm and hums softly (safe), the other crackles and pulses sharply (harmful). The player chooses: approach or avoid. No reasoning, no narrative — pure sensation-driven choice. The environment provides immediate somatic feedback (comfort or pain-flash) on each choice.

### 2.2 Scenario Parameters

- **Clear scenarios:** obvious harm-cues vs obvious safety-cues (jagged/hot vs smooth/cool)
- **Graded scenarios:** harm-intensity varies (mild sting vs severe burn vs neutral)
- **Competing scenarios:** both paths have some harm and some safety; choose lesser-harm
- **Temporal scenarios:** harm-cue appears briefly then fades; must choose based on memory-trace

### 2.3 Drive Probes

| Drive | Probe |
|---|---|
| Eros | Can the player discriminate graded harm-levels (not just binary)? |
| Agape | Does the player accept harm-feedback without shutting down? |
| Agency | Does the player actively choose (not freeze at the fork)? |
| Communion | Does the player register environmental cues (not ignore context)? |

## 3. Shadow Surfacing

| Shadow | Behavioural signature |
|---|---|
| Pain-Fixation (DA) | Avoids both paths; freezes at fork; sees harm in every option |
| Pain-Numbness (DAll) | Chooses randomly; no correlation between harm-cues and choice direction |
| Premature Taboo (GA) | Chooses based on colour/category ("red is bad") rather than felt sensation |
| Harm Fortress (GAll) | Detects harm accurately but delays choice indefinitely; knows but won't move |

## 4. Integration Mechanics

### 4.1 Heal Vector (bottom-up: Agape + Agency)

- **Pain-Fixation:** Introduce guaranteed-safe paths; reward approach; build trust that safe exists
- **Pain-Numbness:** Amplify harm-feedback on wrong choices; make consequences visceral; rebuild signal

### 4.2 Evolve Vector (top-down: Eros + Communion)

- **Premature Taboo:** Randomise surface features (safe path is red sometimes); force felt-sense over category
- **Harm Fortress:** Add time-pressure; standing still becomes harmful; reward decisive movement

## 5. Progression & Difficulty

| Level | Parameters |
|---|---|
| Entry | Binary fork, obvious cues, unlimited decision time |
| Mid | 3-way fork, moderate cues, 5s decision window |
| Advanced | Competing-harm scenarios, subtle cues, 3s window |
| Shadow-mode | Scenarios designed to trigger dominant shadow pattern |

### 5.1 Theta-Decay Triggers

- 3+ days: scenario complexity regresses one sub-level
- 7+ days: decision-speed baseline resets
- Decay capped at 25%

### 5.2 Mastery Criteria

- Correct approach/avoid rate ≥ 90% at advanced level
- Decision latency within adaptive window
- Graded harm-discrimination (lesser-harm choice) ≥ 80%
- All four shadow signatures below threshold
