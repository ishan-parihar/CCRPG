# Cognitive / Amber — Deterministic Game Concept

> **Modality axis:** Objective psychophysics — tasks with correct/incorrect answers, precise timing, algorithmic scoring. The calibration anchor for all other modalities.
> **Why this axis for this module:** Concrete operational thinking IS measurable. Rule-following accuracy, n=2 stability, Corsi-3 reproduction, classification accuracy, and WCST shift-detection are all binary, objective, and the backbone of Amber cognitive assessment.

---

## 1. Game Identity

- **Title:** "The Ledger of Laws"
- **Core mechanic:** The player encounters a rule-governed system and must demonstrate mastery — follow the rule, hold the pattern, reproduce the sequence, classify the items, detect the shift. A living codex that tests whether the player's mind can serve the order.
- **Duration:** 2-4 minutes per session (infinite checkpoints; fatigue-monitored)
- **Internal progression:** The First Law → The Stable Code → The Living Classification → The Shifting Rule → The Master Ledger

---

## 2. Catalyst Delivery

**What this modality uniquely presents:** Pure cognitive challenge with no social, verbal, or embodied mediation. The rule is presented; the player follows or doesn't. Binary. Objective. The contact boundary is engaged directly: "Can your mind serve a system reliably?"

**How this differs from other modalities:** No language required (unlike language-reflective). No decision-making under ambiguity (unlike scenario-choice). No body involvement (unlike embodied-somatic). No planning ahead (unlike strategic-planning). No coordination (unlike social-cooperative). No free-play (unlike immersive-rpg). JUST: here is the rule. Follow it. Now.

**What it uniquely surfaces:** The RAW capacity — stripped of all compensatory strategies. A player who talks well about rules (language-reflective) but fails here has golden-addiction. A player who plans well (strategic-planning) but fails here has a head-body gap. This is ground truth.

**Successful integration:** The player demonstrates concrete operational mastery — stable, flexible, systematic — in pure psychophysical terms.

---

## 3. Game Design

### Setup
The Ledger of Laws: a codex-interface where rules are presented as illuminated pages. The player interacts with the codex — following rules, holding patterns, reproducing sequences, classifying items, detecting shifts. Aesthetic: Amber-stage monastery library — parchment, ink, candlelight, systematic order.

### Interaction
- **The First Law (1-5):** Single rule, follow consistently. "Red goes left. Blue goes right." Binary classification.
- **The Stable Code (5-15):** n=2 holding. "Remember the last TWO. Match the pattern." Sustained accuracy.
- **The Living Classification (15-30):** Multi-criterion sorting. "Sort by colour. Now by shape. Now by function." Flexible classification.
- **The Shifting Rule (30-50):** WCST-lite. The rule changes WITHOUT announcement. Detect and adapt.
- **The Master Ledger (50+):** Full integration: stable holding + flexible classification + shift-detection + sequence reproduction.

### Feedback
- Correct rule-following → "The code holds. You serve the order well. The ledger glows."
- Perseveration → "The rule has changed. Look again. The old law is honoured but the new law is HERE."
- Rule-breaking → "The code awaits. One rule. Simple. Follow it. The door opens for those who serve."
- Premature attempt → "Not yet. Master THIS page first. The next page requires this one to be perfect."
- Shift-avoidance → "The rule changed. That's natural. Rules live. They grow. Watch. See? Safe."

### Difficulty Adaptation
- Rule complexity: binary → ternary → multi-criterion
- Holding load: n=1 review → n=2 stable → n=2 under interference
- Sequence length: Corsi-2 → Corsi-3 → Corsi-3 under load
- Shift frequency: rare → occasional → moderate (never high — that's Orange)
- Classification depth: single-criterion → dual-criterion → hierarchical

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The First Law | 1-5 | Single rule, binary classification |
| The Stable Code | 5-15 | n=2 holding, sustained accuracy |
| The Living Classification | 15-30 | Multi-criterion flexible sorting |
| The Shifting Rule | 30-50 | WCST-lite shift-detection |
| The Master Ledger | 50+ | Full concrete operational integration |

---

## 4. Item Pool

- **Rule-following items:** Binary/ternary classification rules (colour, shape, size, function) — 30+
- **Holding items:** n-back sequences at n=2 (visual, spatial, auditory) — 30+
- **Sequence items:** Corsi-style spatial sequences (length 2-3) — 20+
- **Classification sets:** Multi-criterion sorting sets (20+ items per set) — 20+ sets
- **Shift items:** WCST-style rule-shift trials (old rule → new rule) — 15+

---

## 5. Technical Requirements

- **Input types:** Tap (classify/select); swipe (sort); sequence-tap (Corsi reproduction); hold (sustained attention)
- **Timing:** Response latency tracked (ms precision); inter-trial intervals standardised; session duration monitored for fatigue
- **NPC/AI:** Adaptive difficulty system (IRT-based item selection); perseveration detection algorithm; fatigue detection; shadow-signal accumulator
- **LLM:** None — fully deterministic scoring
- **State persistence:** Full trial history; accuracy per capacity; perseverative error counts; shift-detection latency; d' scores; classification flexibility metrics; Corsi accuracy; cross-session stability; drive/shadow signal accumulation; fatigue indicators; checkpoint position
