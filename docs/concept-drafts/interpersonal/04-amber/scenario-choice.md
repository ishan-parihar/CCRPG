# Interpersonal / Amber — Scenario-Choice Game Concept

> **Axis:** Decision-making when group code conflicts with personal interest — reveals all 4 shadows through choice patterns under relational pressure.
> **Why this axis for this module:** Group-belonging is revealed most clearly when the code's relational demands conflict with personal interest, competing loyalties, or the call to examine the code. The enforcer always chooses code-enforcement, the lone wolf always chooses personal interest, the premature diplomat chooses performed sophistication, the belonging-refuser chooses the code but refuses to examine it.

---

## 1. Game Identity

- **Title:** "The Code's Crossroads"
- **Core mechanic:** The player faces branching scenarios where group obligations conflict with personal interest, competing loyalties, or the call to examine relational demands. Choices reveal the structure of their group-belonging. No choice is "wrong" — but each is diagnostic.
- **Duration:** 4-10 minutes per session
- **Internal progression:** The Simple Obligation → The Competing Loyalty → The Costly Membership → The Code Questioned → The Member's Choice

---

## 2. Catalyst Delivery

**What this modality uniquely presents:** The DECISION dimension of group-belonging — how the player chooses when the code's relational demands conflict with personal interest. Unlike deterministic (raw coordination accuracy), this modality measures the QUALITY of relational choice under group-moral pressure.

**How this differs from other modalities:** Unlike language-reflective (verbal articulation), this modality measures actual choice behaviour under relational conflict. A player who articulates group-belonging beautifully but chooses personal interest here has a language-behaviour gap. A player who cannot articulate but chooses code-consistently has implicit group-belonging.

**What it uniquely surfaces:** All 4 shadow quadrants through choice patterns. The enforcer always chooses code-enforcement. The lone wolf always chooses personal interest. The premature diplomat chooses the "relationally sophisticated" option. The belonging-refuser chooses the code but refuses to examine the choice.

**Successful integration:** The player makes contextually appropriate relational choices — following the code when appropriate, asserting personal interest when appropriate, examining the code when appropriate.

---

## 3. Game Design

### Setup
The Code's Crossroads: a narrative interface presenting relational conflicts within an Amber-stage world. Each scenario has 3-4 choices representing different relational responses. Aesthetic: Amber-stage world — guild halls, order meetings, the weight of collective obligation.

### Interaction
- **The Simple Obligation (1-5):** Clear group obligation, clear personal interest. "Your guild needs you tonight. You had personal plans. What do you do?" Tests basic code vs. personal interest.
- **The Competing Loyalty (5-15):** Two group obligations conflict. "Your guild and your family both need you. The code gives no clear answer. What do you do?" Tests loyalty hierarchy.
- **The Costly Membership (15-30):** Following the code costs significantly. "Staying loyal to the guild means losing a personal opportunity. What do you do?" Tests genuine vs. performed loyalty.
- **The Code Questioned (30-50):** The code's relational demand is challenged. "Your elder says the code's requirement here is unjust. Do you examine it? Follow it anyway? Refuse it?" Tests relational examination capacity.
- **The Member's Choice (50+):** Full integration: competing loyalties + cost + examination + sovereign choice simultaneously.

### Feedback
- Code followed with awareness → "You served the guild. And you knew it was a choice. The member is both free and bound."
- Code followed compulsively → "You served the code. But was this a choice? The crossroads asks: can you serve AND choose?"
- Personal interest chosen → "You chose yourself. The code's demand was set aside. Notice: was this sovereign or was this avoidance?"
- Relational sophistication chosen → "You held space for all perspectives. But did you feel the loyalty? The crossroads asks for the belonging, not the framework."
- Code examination → "You questioned the demand. This is not betrayal — this is wisdom. The group grows stronger when examined."

### Difficulty Adaptation
- Conflict intensity: mild → moderate → severe → identity-level
- Loyalty hierarchy complexity: simple → competing → multi-layered
- Examination depth: gentle → direct → fundamental
- Choice consequences: immediate → delayed → cross-session

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The Simple Obligation | 1-5 | Single code-obligation vs. personal interest |
| The Competing Loyalty | 5-15 | Two group obligations in conflict |
| The Costly Membership | 15-30 | Genuine vs. performed loyalty |
| The Code Questioned | 30-50 | Relational demand examined |
| The Member's Choice | 50+ | Full group-belonging integration under maximum pressure |

## 4. Item Pool

- **Simple obligation scenarios:** Single code-obligation vs. personal interest — 25+
- **Competing loyalty scenarios:** Two group obligations in conflict — 20+
- **Costly membership scenarios:** Genuine vs. performed loyalty tests — 20+
- **Code-examination scenarios:** Relational demand challenged — 15+
- **Integration scenarios:** Multi-dimensional relational conflicts — 10+

---

## 5. Technical Requirements

- **Input types:** Tap (choice selection); hold (deliberation); swipe (scenario navigation)
- **Timing:** Choice latency tracked; deliberation time measured; avoidance patterns detected
- **NPC/AI:** Adaptive scenario selection based on shadow-signal accumulation; consequence-delivery; cross-session narrative continuity; drive-health signal extraction from choice patterns
- **LLM:** Consequence narration; scenario adaptation; choice-quality assessment for ambiguous cases
- **State persistence:** Full choice history; shadow-pattern tracking; drive-health signal accumulation; cross-session narrative coherence; relational-conflict history; checkpoint position
