# Interpersonal / Amber — Immersive-RPG Game Concept

> **Axis:** Ecological group-belonging — whether role-based coordination appears spontaneously in free-play, without structured prompts or explicit coordination tasks.
> **Why this axis for this module:** The deepest test of group-belonging is whether it appears SPONTANEOUSLY in unstructured contexts. A player who coordinates well in structured tasks but ignores group obligations in free-play has compartmentalised capacity. The immersive-RPG reveals whether group-belonging has genuinely transferred to lived relational behaviour.

---

## 1. Game Identity

- **Title:** "The Living Order"
- **Core mechanic:** The player inhabits a role within an Amber-stage world and navigates a free-play environment where group obligations arise naturally. No explicit coordination tasks — the player's group-belonging is revealed through spontaneous relational choices, role-consistent behaviour, and how they handle the inevitable tensions between group code and personal interest.
- **Duration:** 8-20 minutes per session (open-ended; player-determined)
- **Internal progression:** Taking the Role → The Group's World → The Code Invoked → The Belonging Tested → The Living Order

---

## 2. Catalyst Delivery

**What this modality uniquely presents:** The ECOLOGICAL dimension of group-belonging — whether role-based coordination appears spontaneously in unstructured contexts. Unlike all other modalities (which present explicit coordination challenges), this modality observes the player's natural relational behaviour in a world that has group obligations embedded in it.

**How this differs from other modalities:** Unlike deterministic, language-reflective, scenario-choice, embodied-somatic, strategic-planning, and social-cooperative — this modality presents NO explicit coordination challenges. The player simply inhabits the world. Their group-belonging (or lack of it) emerges naturally.

**What it uniquely surfaces:** Whether group-belonging has genuinely transferred to lived relational behaviour. The enforcer will find code-violations everywhere and cannot rest. The lone wolf will ignore group obligations spontaneously. The premature diplomat will perform sophisticated relating without genuine belonging. The belonging-refuser will stay in known relational territory and refuse novel group obligations.

**Successful integration:** The player inhabits their role relationally — coordinating through the code when it arises, resting when appropriate, adapting when the world demands it — without either compulsive enforcement or spontaneous desertion.

---

## 3. Game Design

### Setup
The Living Order: an open-world RPG environment set in an Amber-stage world. The player has a role (guild member, order knight, temple keeper) with associated group obligations. The world presents situations that naturally invoke group-belonging — without labelling them as "coordination challenges." Aesthetic: Amber-stage world — guild structures, order hierarchies, the lived texture of collective belonging.

### Interaction
- **Taking the Role (1-5):** Player selects a role and receives its associated group obligations. "As a guild member, you are expected to: coordinate with your fellows, honour the code, maintain your role." No explicit tasks — just the role.
- **The Group's World (5-15):** The world presents situations that invoke group obligations. A fellow member needs help. The code requires a response. A group task arises. The player responds (or doesn't) spontaneously.
- **The Code Invoked (15-30):** The world presents situations where the code's relational demands are invoked. A conflict arises. A deviation occurs. The player's spontaneous response is observed.
- **The Belonging Tested (30-50):** The world presents situations where group-belonging itself is tested. A temptation to desert. A call to examine the code. The player's spontaneous response is observed.
- **The Living Order (50+):** Full integration: spontaneous coordination + code-invocation + belonging-maintenance — all in free-play.

### Feedback
- Role-consistent relational behaviour → "The guild member acts as a guild member. The world notices. The order's life is alive."
- Role-inconsistent relational behaviour → "The member acted outside the code. The world noticed. What does this mean for the belonging?"
- Compulsive enforcement → "The member finds code-violations everywhere. Even in rest. The order asks: can you belong AND rest?"
- Relational desertion → "The member passed the fellow without coordinating. The code was not invoked. Was this a choice or an absence?"
- Code examination → "The member questioned the code. This is not betrayal — this is wisdom. The order grows stronger when examined."

### Difficulty Adaptation
- World relational complexity: simple obligations → competing → multi-layered
- Code-invocation frequency: rare → occasional → frequent
- Belonging-test intensity: mild → moderate → severe
- Role complexity: single obligation → multiple → hierarchy

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| Taking the Role | 1-5 | Role selection and group obligation awareness |
| The Group's World | 5-15 | Spontaneous group-coordination response |
| The Code Invoked | 15-30 | Spontaneous code-invocation response |
| The Belonging Tested | 30-50 | Spontaneous belonging-maintenance response |
| The Living Order | 50+ | Full ecological group-belonging integration |

## 4. Item Pool

- **Group obligation scenarios:** Situations invoking group coordination spontaneously — 30+
- **Code-invocation scenarios:** Situations requiring spontaneous code-application — 25+
- **Belonging-test scenarios:** Situations testing group-belonging spontaneously — 20+
- **Rest scenarios:** Situations where relational rest is appropriate — 15+
- **Novel obligation scenarios:** Situations presenting new group obligations — 15+

---

## 5. Technical Requirements

- **Input types:** Tap (action selection); hold (deliberation); swipe (world navigation); free movement
- **Timing:** Response latency to group-obligation situations tracked; code-invocation response time measured; belonging-test engagement duration recorded
- **NPC/AI:** World-event generation based on role and shadow-signal accumulation; group-obligation invocation calibration; belonging-test generation; ecological relational behaviour analysis
- **LLM:** World narration; NPC dialogue; consequence delivery; group-obligation invocation naturalness; code-examination depth
- **State persistence:** Full world-interaction history; spontaneous coordination patterns; code-invocation responses; belonging-test engagement; role-consistency tracking; cross-session world-state continuity; drive/shadow signal accumulation; checkpoint position
