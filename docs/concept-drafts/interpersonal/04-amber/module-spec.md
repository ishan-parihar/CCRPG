# Interpersonal / Amber — Module Specification

> **Line:** Interpersonal (coordination, attunement, relational intelligence)
> **Stage:** Amber / Mythic-Membership (conformist, rule-following, group-belonging)
> **Vibration:** The code that binds us — "We follow the rules together." Relationships are no longer transactional (Red) but role-structured: each person has a place, a duty, and a way of relating that the code defines.

---

## 1. Capacity Definition

Interpersonal intelligence at Amber is **role-based coordination** — the capacity to relate to others through shared code, coordinate through group obligations, maintain role-appropriate behaviour toward others, and resolve conflicts through the code rather than through power or transaction.

**Key distinction from Red:** Red interpersonal is transactional — "What can you do for me?" Amber interpersonal is role-structured — "What does the code require of us toward each other?" Red has first loyalty bonds (war-band); Amber has genuine group-belonging (the order, the guild, the tribe).

**Key distinction from Orange:** Orange interpersonal is contractual — "What did we agree to?" Amber interpersonal is code-bound — "What does our tradition require?" Amber cannot yet negotiate the code; Orange can.

### Core capacity dimensions

| Dimension | Definition | Assessment vehicle | Ceiling at this stage |
|---|---|---|---|
| **Role-reading** | Identifies others' roles and the behaviour those roles require | Role-congruent behaviour recognition tasks | Accurate for 4+ roles across 2+ contexts |
| **Code-coordination** | Coordinates with others through shared obligations | Multi-step code-based coordination tasks | 3-step coordination through shared code |
| **Loyalty-maintenance** | Maintains group-belonging across time and adversity | Cross-session loyalty tracking; adversity-loyalty tasks | Loyalty holds across 7+ interactions |
| **Conflict-through-code** | Resolves interpersonal conflicts by appealing to the code | Code-based conflict resolution tasks | Resolves 2-party conflict through code appeal |
| **Role-appropriate boundary** | Asserts and respects role-appropriate limits | Role-boundary tasks; code-limit scenarios | Maintains role-appropriate limits in 3+ contexts |

### What this is NOT

- **NOT Red:** Red interpersonal is transactional. Amber is role-structured. Red has first loyalty; Amber has genuine group-belonging.
- **NOT Orange:** Orange interpersonal is contractual and negotiated. Amber is code-bound and given. Amber cannot yet question whether the code's relational demands are appropriate.

## 2. Shadow Archetypes

### 2.1 Dark-Addiction: "The Enforcer"

**Core pattern:** Enforces the group code on everyone rigidly. Cannot tolerate code-deviation. Relationships are code-compliance contests. The code is not a guide for relating — it is a weapon for controlling.

**Drive pathology:**
- Agency: Dominates all relational space through code-enforcement; "The code says you must"
- Communion: Cannot join; only enforce; relationships are compliance hierarchies
- Eros: Cannot grow relationally beyond current code; new relational forms are "violations"
- Agape: Cannot return to simple coordination; everything must be code-enforcement

**Behavioural signatures:**
- Monitors others' code-compliance obsessively
- Cannot tolerate any deviation, even minor or contextual
- Treats all relational conflicts as code-violations requiring enforcement
- Cannot form relationships outside the code-structure
- Punishes code-deviation even when the code-giver would not
- Relationships are defined entirely by compliance/non-compliance

**Atman Project defenses:** Code-weaponisation, relational rigidity, enforcement-as-identity.

**What "healed" looks like:** Can coordinate through the code AND relate to people as people. Enforcement is proportional and compassionate. The code serves the relationship; the relationship is not consumed by the code.

---

### 2.2 Dark-Allergy: "The Lone Wolf"

**Core pattern:** Refuses group-belonging. Stays in Red transactional mode — others are instruments, not members. Cannot coordinate through shared code. The call to genuine group-belonging is experienced as loss of sovereignty.

**Drive pathology:**
- Agency: Acts solo; cannot bind relational behaviour to group code
- Communion: Cannot join the group; "I'll coordinate when it serves me"
- Eros: Reaches for new relational experiences without group-grounding
- Agape: Cannot return to group-belonging; "I was never a joiner"

**Behavioural signatures:**
- Refuses role-assignments; "I don't have a role"
- Cannot coordinate through shared obligations; "I'll do what I want"
- No loyalty-maintenance; relationships are purely transactional
- Treats group-belonging as weakness or imprisonment
- Cannot resolve conflicts through the code; uses power or transaction instead
- Interpersonal relationships are shallow and instrumental

**Atman Project defenses:** Relational commitment-avoidance, Red-stage fixation, sovereignty-identification.

**What "healed" looks like:** Can accept a role within a group. Can coordinate through shared obligations. Can feel the warmth of genuine group-belonging.

---

### 2.3 Golden-Addiction: "The Premature Diplomat"

**Core pattern:** Performs sophisticated relational behaviour (Orange contractual, Green pluralistic) without genuine Amber group-belonging underneath. Claims to "understand all perspectives," "negotiate fairly," and "hold space for everyone" — but cannot feel simple loyalty or coordinate through a shared code.

**Drive pathology:**
- Agency: Performed relational sovereignty without genuine group-belonging
- Communion: Over-developed in FORM — "validates" everyone without genuine joining
- Eros: Compulsive reaching toward relational sophistication; cannot rest in simple group-membership
- Agape: Cannot return to simple code-coordination; "That's too basic for me"

**Behavioural signatures:**
- Uses sophisticated relational language without genuine group-belonging
- High language-reflective scores + low code-coordination scores = golden-addiction signal
- Cannot feel genuine loyalty (only performs loyalty-language)
- Conflict resolution is performed, not code-grounded
- Cross-validation: articulates relational complexity but fails role-reading tasks

**Atman Project defenses:** Relational bypass, Orange-stage performance without Amber foundation.

**What "healed" looks like:** Can feel simple group-belonging genuinely before engaging relational sophistication. Loyalty is felt, not performed. Code-coordination is genuine, not performed.

---

### 2.4 Golden-Allergy: "The Belonging-Refuser"

**Core pattern:** Group-belonging is PRESENT but the call to relational depth/examination (Orange) is refused. Cannot examine whether the code's relational demands are appropriate. "We relate as the code says — I don't need to examine it." Relational life is code-justified and unexaminable.

**Drive pathology:**
- Agency: Cannot assert independent relational reasoning
- Communion: Clings to group's relational code; fears individual relational examination
- Eros: Refuses the call to examine and potentially revise relational demands
- Agape: Over-embodies current relational code; makes it permanent and sacred

**Behavioural signatures:**
- Excellent role-reading and code-coordination
- But: freezes when asked "why does the code require this of us?"
- Treats relational examination as betrayal or weakness
- Cannot distinguish between healthy code-coordination and destructive code-compliance
- Anxiety or hostility when relational demands are examined

**Atman Project defenses:** Relational code-sacralisation, Orange-refusal, examination-avoidance.

**What "healed" looks like:** Can coordinate through the code AND examine it. Can ask "is this relational demand appropriate?" without experiencing the question as betrayal.

## 4. Healing Vectors

### 4.1 Heal/Evolve (Agape + Agency → dark shadows)

**For The Enforcer:**
- Agape: Return to the PERSON beneath the role. "The code serves the people; the people are not consumed by the code."
- Agency: Sovereign examination of each enforcement. "Is this proportional? Do I choose this enforcement?"
- Mechanism: Present situations where the code requires MERCY, not enforcement. "The code says: know when to hold and when to release."

**For The Lone Wolf:**
- Agape: Return to the group with compassion. "They are not a threat. They are your people. Can you feel even a small part of that?"
- Agency: Own the group-membership as a sovereign choice. "Not because you must — because you CHOOSE to belong."
- Mechanism: Ultra-small belonging-moments. "Hold this role for one interaction. Notice it. That's enough."

### 4.2 Evolve/Heal (Eros + Communion → golden shadows)

**For The Premature Diplomat:**
- Eros: Reach toward GENUINE group-belonging (not performed). "Feel the loyalty first. Then the sophistication."
- Communion: Join with others at the ACTUAL relational level. "Not 'I understand all perspectives' — 'I am one of you.'"
- Mechanism: Lock relational sophistication tasks behind demonstrated group-belonging. Simple genuine membership must precede complex relational performance.

**For The Belonging-Refuser:**
- Eros: Reach toward the QUESTION (not the answer). "Why does the code require this of us? Not to change it — to understand it."
- Communion: Join with others who examine AND honour their relational code. "They question AND they belong. Both are possible."
- Mechanism: Introduce gentle meta-cognitive tasks about relational demands. "Notice the code. Don't change it. Just notice why it requires this."

### 4.3 Integration criteria

The player demonstrates: genuine group-belonging without code-fusion; role-reading accuracy; code-coordination without rigidity; loyalty-maintenance without compulsion; conflict-resolution through code without enforcement; openness to examining relational demands.

### Shadow-drag coefficient: 0.20

## 6. Compound Shadows & Cross-Module Relationships

### 6.1 The Dogmatic Enforcer (Interpersonal × Cognitive, both dark-addiction)

**Loop:** Rigid group code (Interpersonal) + rigid rule-following (Cognitive) = fundamentalist group-think. The code is enforced cognitively and relationally. No deviation is tolerable in thought or in relationship.

**Bidirectional mechanism:**
- Cognitive dark-addiction → "The rules are absolute" → rigid code-enforcement
- Interpersonal dark-addiction → "The group must comply" → more cognitive rigidity

**Break point:** Present situations where the code requires FLEXIBILITY. "The rule serves the group; the group is not consumed by the rule."

---

### 6.2 The Lone Wolf (Interpersonal × Willpower, both dark-allergy)

**Loop:** Refuses group-belonging (Interpersonal) + refuses sustained commitment (Willpower) = isolated impulsivity. Cannot join AND cannot commit. Every relationship is transactional and brief.

**Bidirectional mechanism:**
- Willpower allergy → "I can't sustain commitment" → cannot maintain group-belonging
- Interpersonal allergy → "I don't need the group" → no motivation to sustain commitment

**Break point:** Present a group that requires ONLY brief commitment. "Just this one task. Together. Then you're free."

---

### 6.3 The Charming Manipulator (Interpersonal golden-addiction × Emotional dark-allergy)

**Loop:** Performs sophisticated relating (Interpersonal) without genuine role-affect (Emotional). The relational performance is sophisticated but emotionally hollow. Charm without feeling.

**Bidirectional mechanism:**
- Emotional allergy → "I don't feel the group's emotions" → relational performance substitutes for genuine feeling
- Interpersonal golden-addiction → "I perform relating well" → no need to develop genuine emotional connection

**Break point:** Require FELT group-emotion before relational sophistication. "Not the performance — the feeling. Can you feel the loyalty?"

---

### 6.4 The Frozen Conformist (Interpersonal × Intrapersonal, both dark-addiction)

**Loop:** Rigid group-belonging (Interpersonal) + rigid role-identity (Intrapersonal) = cannot think independently. The self IS the role; the role IS the group. No individual thought or feeling is possible.

**Bidirectional mechanism:**
- Intrapersonal dark-addiction → "I am my role" → cannot relate outside the role
- Interpersonal dark-addiction → "The group defines me" → deeper role-identity fusion

**Break point:** Present situations where the self and the role can be distinguished. "You are a member of the order. AND you are you. Both are true."

### Dependencies
- **Supports:** Moral/Amber (group-belonging enables conventional morality); Emotional/Amber (role-coordination requires role-affect)
- **Depends on:** Willpower/Amber (sustained commitment enables loyalty-maintenance); Cognitive/Amber (rule-following enables code-coordination)

## 7. Shadow Surfacing Sequence

### 7.1 Progressive revelation order

1. **Role-reading** → Dark-allergy surfaces first (cannot read roles = immediately visible)
2. **Code-coordination** → Dark-addiction surfaces (enforcement vs. coordination)
3. **Loyalty-maintenance** → Dark-allergy deepens (cannot maintain group-belonging)
4. **Conflict-through-code** → Dark-addiction deepens (enforcement vs. resolution)
5. **Code-examination** → Golden-allergy surfaces (refusal to examine relational demands)
6. **Relational sophistication tasks** → Golden-addiction surfaces (performance without genuine belonging)

### 7.2 Per-modality surfacing

| Modality | Dark-Addiction signal | Dark-Allergy signal | Golden-Addiction signal | Golden-Allergy signal |
|---|---|---|---|---|
| Deterministic | Enforces code on all interactions; cannot coordinate | Cannot read roles; treats all as transactional | High verbal sophistication + low coordination accuracy | Avoids relational examination tasks |
| Language-reflective | Absolute code-language; "The code requires" | "I relate as I choose" (Red-stage language) | Sophisticated relational vocabulary without genuine belonging | Refuses to discuss WHY the code requires this |
| Scenario-choice | Chooses code-enforcement regardless of context | Chooses transactional option over code-based | Chooses relational sophistication over simple belonging | Chooses code-coordination but refuses to examine it |
| Embodied-somatic | Body rigid with enforcement-posture | Body disconnected from group-belonging | Body performs relational attunement without genuine feeling | Body holds group-posture but freezes at novel relational demands |
| Strategic-planning | Plans code-enforcement obsessively | Cannot plan group coordination; impulsive | Plans relational sophistication without belonging foundation | Refuses to plan beyond current relational code |
| Social-cooperative | Enforces code on group members | Cannot coordinate through shared obligations | Performs group coordination without genuine belonging | Defers all relational reasoning to group code |
| Immersive-rpg | Finds code-violations everywhere; cannot rest | Ignores group-belonging cues; isolated | Performs relational sophistication spontaneously without genuine belonging | Stays in known relational territory; refuses novel group-belonging |

### 7.3 Cross-validation rules
- Deterministic high + Language-reflective low = implicit code-coordination without metacognition (normal early)
- Language-reflective high + Deterministic low = verbal performance without genuine belonging (golden-addiction)
- Social-cooperative high + Deterministic low = group-dependent coordination (communion-addiction)
- Loyalty-maintenance high + conflict-through-code low = belonging without resolution capacity (partial integration)
