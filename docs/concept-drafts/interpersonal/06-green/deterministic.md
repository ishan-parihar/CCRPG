# Interpersonal / Green — Deterministic Game Concept

> **Axis:** Objective relational measurement — listening accuracy, perspective-taking precision, conflict-resolution effectiveness.  **Why this axis for this module:** Authentic relating has measurable behavioural signatures; deterministic tasks isolate relational skill from verbal fluency, social performance, or embodied expression.

---

## 1. Game Identity

**Name:** Resonance Field  
**Core loop:** Player observes multi-party relational exchanges and must identify emotional states, relational dynamics, perspective-positions, and optimal conflict-resolution moves — all through objective selection rather than free expression.  
**Session length:** 4–8 minutes per checkpoint.  
**Infinite checkpoint:** Each exchange set is self-contained; player exits between any two exchanges.

## 2. Catalyst Delivery

**Shadow surfacing:** DAll surfaces when player consistently selects "professional" or "contractual" interpretations of genuinely vulnerable exchanges. DA surfaces when player cannot distinguish authentic mutuality from enmeshed fusion — selecting "deep connection" for boundary-violating dynamics.  
**Drive probing:** Agency measured by capacity to identify healthy boundaries within mutual vulnerability. Communion measured by capacity to recognise genuine joining vs. performed connection. Eros measured by recognition of growth-edges in relational exchanges. Agape measured by recognition of embodied presence vs. collapse.  
**Catalyst→Experience→Integration:** Exchanges begin at player's current edge, surface shadow through systematic error analysis, then offer corrective exchanges that model healthy relating at the exact point of confusion.

## 3. Game Design

**Stimulus format:** Animated vignettes showing 2–4 characters in relational exchange. Facial micro-expressions, body language, vocal tone, and dialogue content carry independent information.  
**Task types:**  
- *Perspective identification:* "What is Character B's actual felt experience?" (4 options — one correct, three shadow-distorted)  
- *Dynamic classification:* "What relational pattern is operating?" (mutual vulnerability / enmeshment / contractual / performed depth)  
- *Resolution selection:* "Which response deepens authentic relating without boundary violation?" (4 options calibrated to shadow quadrants)  
- *Boundary detection:* "Where does mutual vulnerability end and enmeshment begin?"  
**Adaptive difficulty:** Adjusts via number of characters, ambiguity of cues, subtlety of shadow-pattern distinction, and cross-cultural relational norms.  
**Scoring:** Response accuracy × latency weighting. Systematic error patterns map to shadow quadrants.

## 4. Item Pool

**Structure:** 200+ vignettes across 4 relational contexts (dyadic intimate, friendship, group, professional-becoming-authentic). Each tagged with: target shadow, drive probed, difficulty tier (1–5), cultural context.  
**Shadow-specific items:** DA items show enmeshment presented as intimacy. DAll items show authentic vulnerability presented ambiguously. GA items show spiritual language masking relational avoidance. GAll items show authentic relating at a growth-edge.  
**Refresh:** Vignettes rotate on 30-day cycles. No exact repetition within 90 days.

## 5. Technical Requirements

**Rendering:** Pre-rendered animated vignettes (2D character animation with facial expression system). Audio channel for vocal tone. Subtitle option for accessibility.  
**Timing:** 800ms minimum display before response enabled. 12s maximum response window. Latency recorded at 16ms precision.  
**Adaptive engine:** 3-parameter IRT model (difficulty, discrimination, guessing). Shadow-pattern detection via sliding window of 20 responses. Drive-health updated per 5-item block.  
**Data:** Per-item response + latency stored. Cross-modality validation flags emitted at 0.7 confidence.  
**Accessibility:** Full audio description mode. High-contrast facial expression overlays. Adjustable playback speed (0.75x–1.5x).
