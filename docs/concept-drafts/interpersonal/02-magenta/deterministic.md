# Interpersonal / Magenta — Deterministic Game Concept

> **Axis:** The deterministic axis probes interpersonal intelligence through OBJECTIVE MEASUREMENT — can the player detect another's presence, state, and movement with measurable accuracy? At Magenta, this is: "Is something there? What is it doing? Can you track it?" Pure other-detection before relationship.
>
> **Why this axis for Interpersonal/Magenta:** Before relating (Red+), there must be SENSING. At Magenta: "Something is there." The simplest interpersonal act — detecting another presence. This modality tests whether the player can perceive another being at all.

---

## 1. Game Identity

- **Title:** "The Presence-Sense"
- **Core mechanic:** Phantom-allies appear and the player must detect their presence, location, and state. Not interaction — just DETECTION. Can they sense that something else is there? The pre-relational foundation of all interpersonal capacity.
- **Duration:** 2-4 minutes per session (infinite checkpoints; fatigue-aware)
- **Internal progression:** The First Presence → The Moving Presence → The Feeling Presence → The Hidden Presence → The Living Other

---

## 2. Catalyst Delivery

**Catalyst:** "Something is here. Can you sense it? Where? What is it feeling? Is it moving?" The contact boundary is: "Can you detect another being?"

**Unconscious response:**
- *Submergent:* How does the player relate to other-presence? The Fusion-Addict is overwhelmed by every presence. The Phantom-Denier detects nothing. The Premature Coordinator reports sophisticated observations without genuine sensing. The Bond-Refuser detects then disengages.
- *Emergent:* Can they detect presence accurately without dissolving or denying?

**Integration path:** Rewards ACCURATE OTHER-DETECTION — sensing presence, location, state, and movement without fusion or denial. Calibrated other-sensing.

**Successful integration:** The player reliably detects another's presence, location, and basic state — the foundation for all later relating.

---

## 3. Game Design

### Setup
The Presence-Sense: a detection space where phantom-allies appear and the player must sense them. The aesthetic: Magenta-stage spirit-world — glowing presences that shimmer in and out of visibility. The player's task is simply to NOTICE them.

### Interaction
- **The First Presence (1-5):** Clear, obvious presence → "Is something there?" Binary detection.
- **The Moving Presence (5-15):** Presence moves → "Where is it now?" Location tracking.
- **The Feeling Presence (15-30):** Presence has emotional state → "What is it feeling?" State detection.
- **The Hidden Presence (30-50):** Presence is subtle → "Can you still sense it?" Threshold detection.
- **The Living Other (50+):** Full presence-sensing: detect → locate → state → track → distinguish.

### Feedback
- Accurate detection → "You sensed it! Something IS there. You can feel other beings."
- Fusion → "Too close. You merged with it. Stay HERE. Sense it from HERE."
- Nothing → "Something IS there. Stronger now. Can you feel it? Even a little?"
- Over-precise → "Simpler. Is it there? Yes or no. Just that. Feel it, don't analyse it."
- Disengage → "You sensed it! Keep sensing. Just notice. You don't have to do anything else."

### Difficulty Adaptation
- Presence intensity: strong (easy to detect) → moderate → subtle → barely-there
- Presence movement: stationary → slow → fast → unpredictable
- Presence state: single emotion → shifting → mixed → ambiguous
- Multiple presences: one → two → three (distinguishing)
- Detection format: binary (there/not-there) → location → state → full profile

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The First Presence | 1-5 | Binary detection (there/not-there) |
| The Moving Presence | 5-15 | Location tracking |
| The Feeling Presence | 15-30 | Emotional state detection |
| The Hidden Presence | 30-50 | Subtle/threshold detection |
| The Living Other | 50+ | Full presence-sensing integration |

---

## 4. Item Pool Specification

### Item types
- **Clear presences:** Obvious, strong, easy to detect
- **Moving presences:** Change location; require tracking
- **Feeling presences:** Have emotional states to identify
- **Hidden presences:** Subtle; near detection threshold
- **Multiple presences:** Two or more; require distinguishing

### Minimum pool size
- 25+ clear, 20+ moving, 15+ feeling, 15+ hidden, 10+ multiple

### Drive/shadow mapping
- Fusion/overwhelm on detection → dark-addiction; zero detection → dark-allergy
- Over-precise/mechanical detection → golden-addiction; detect-then-disengage → golden-allergy

---

## 5. Technical Requirements

### Input types
- Tap (indicate presence location); select (state identification); swipe (track movement); hold (sustain detection)

### Timing requirements
- Detection latency tracked (ms); tracking accuracy over time; false alarm timing

### NPC/AI requirements
- Phantom-ally system (presences with location, state, movement patterns)
- Presence intensity control (strong → subtle)
- Multiple presence management (distinguishing)
- Optional: companion who shares detection observations

### LLM requirements
- **Low:** Primarily algorithmic. Presence generation, state assignment, movement patterns all pre-designed. LLM only for ecological context and feedback narratives.

### State persistence
- Detection accuracy rates; false alarm rates; location accuracy; state accuracy; tracking accuracy; fusion indicators (overwhelm on detection); denial indicators (zero detection); over-precision indicators; disengagement indicators; drive/shadow signals; fatigue state; checkpoint position
