# Interpersonal / Magenta — Language-Reflective Game Concept

> **Axis:** The language-reflective axis probes interpersonal intelligence through WORDS ABOUT OTHERS — can the player name what they sense about another? At Magenta, this is: "Something is there. What is it? Can you say what it's like?" The first words for other-beings.
>
> **Why this axis for Interpersonal/Magenta:** Before sophisticated relational language (Red+), there must be NAMING the other. At Magenta: "It's a friend." "It's scary." "It's warm." The simplest verbal labels for sensed presences. This modality tests whether the player can bridge other-sensing and language.

---

## 1. Game Identity

- **Title:** "The Other-Word"
- **Core mechanic:** The player senses a presence and must find words for it. Not describing relationship (Red+) — describing the OTHER. "What is it like? Warm? Cold? Big? Small? Friend? Stranger?" The first vocabulary of other-beings.
- **Duration:** 2-4 minutes per session (infinite checkpoints; fatigue-aware)
- **Internal progression:** The First Name → The Other-Feeling → The Presence-Story → The Shared Name → The Speaking Bond

---

## 2. Catalyst Delivery

**Catalyst:** "You sense something there. What would you call it? What is it like? Can you find a word for this other?" The contact boundary is: "Can you name what you sense about another being?"

**Unconscious response:**
- *Submergent:* How does the player verbalise other-presence? The Fusion-Addict cannot separate self-words from other-words ("it's me" / "we are..."). The Phantom-Denier has no words because nothing is sensed. The Premature Coordinator produces elaborate descriptions without genuine sensing. The Bond-Refuser names then stops ("it's there. That's all.").
- *Emergent:* Can they find simple, genuine words for what they sense about the other?

**Integration path:** Rewards GENUINE OTHER-NAMING — simple, accurate words that match what is actually sensed. Not self-other confusion, not nothing, not over-elaborate, not truncated.

**Successful integration:** The player finds words for other-presences that are simple, genuine, and accurate — the seed of relational language.

---

## 3. Game Design

### Setup
The Other-Word: a naming space where presences appear and the player finds words for them. The aesthetic: Magenta-stage spirit-naming — presences shimmer and the player's words give them form. When named accurately, the presence solidifies. When named poorly, it remains vague.

### Interaction
- **The First Name (1-5):** Clear presence → one word. "What is it?" Simple naming.
- **The Other-Feeling (5-15):** Presence has emotional quality → "What does it feel like?"
- **The Presence-Story (15-30):** Multiple words → build a brief description of the other.
- **The Shared Name (30-50):** Name WITH companion → shared other-vocabulary.
- **The Speaking Bond (50+):** Full other-naming: sense → name → describe → share → bond through words.

### Feedback
- Genuine simple naming → "Yes! That's what it's like. Your word found it."
- Self-referential → "Not you. IT. What is IT like? Something different from you."
- Nothing → "Something IS there. Just one word. Any word. What comes to mind?"
- Over-elaborate → "Simpler. One word. What do you FEEL about it?"
- Truncated → "Good! One more? Just one more word about it?"

### Difficulty Adaptation
- Presence clarity: obvious → moderate → subtle
- Naming format: binary choice → select from 4 → generate own word
- Description length: one word → two words → brief phrase
- Presence complexity: simple → mixed qualities → ambiguous
- Sharing requirement: solo naming → shared naming → co-created vocabulary

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The First Name | 1-5 | One word for a clear presence |
| The Other-Feeling | 5-15 | Emotional quality naming |
| The Presence-Story | 15-30 | Multi-word descriptions |
| The Shared Name | 30-50 | Shared naming with companion |
| The Speaking Bond | 50+ | Full other-naming integration |

---

## 4. Item Pool

### Item types
- **Clear presences:** Obvious qualities, easy to name
- **Feeling presences:** Emotional qualities requiring affect-words
- **Complex presences:** Multiple qualities requiring multi-word descriptions
- **Ambiguous presences:** Unclear qualities testing naming under uncertainty
- **Shared presences:** Requiring co-naming with companion

### Minimum pool size
- 25+ clear, 20+ feeling, 15+ complex, 15+ ambiguous, 10+ shared

### Drive/shadow mapping
- Self-referential naming → dark-addiction; empty naming → dark-allergy
- Over-elaborate naming → golden-addiction; truncated naming → golden-allergy

---

## 5. Technical Requirements

### Input types
- Text input (generated words); select from options (binary/multiple choice); voice (optional); collaborative input (shared naming)

### Timing requirements
- Naming latency tracked; no time pressure; response length monitored

### NPC/AI requirements
- Presence system with defined qualities (for validation)
- Naming evaluation (does the word match the presence?)
- Self-other distinction detection (is the naming self-referential?)
- Companion for shared naming phases

### LLM requirements
- **Very High:** Evaluates open-ended naming; detects self-referential language; assesses vocabulary quality; distinguishes genuine from performed naming; facilitates shared naming.

### State persistence
- Naming accuracy rates; self-other distinction scores; vocabulary range; naming consistency; sharing quality; self-referential indicators; empty-naming indicators; over-elaboration indicators; truncation indicators; drive/shadow signals; fatigue state; checkpoint position
