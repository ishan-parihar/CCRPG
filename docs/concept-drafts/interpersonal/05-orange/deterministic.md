# Interpersonal / Orange — Deterministic Game Concept

> **Axis:** Objective relational measurement — contract clarity, expectation-setting accuracy, boundary precision.  **Why this axis for this module:** Orange interpersonal capacity is fundamentally about explicit coordination; deterministic mechanics isolate the structural skill of contract-making from social/verbal/embodied confounds.

---

## 1. Game Identity

**Title:** Contract Architect  
**Core loop:** Player constructs, evaluates, and repairs relational contracts between abstract parties with quantifiable parameters. Each contract specifies roles, expectations, boundaries, and exit conditions. Scoring is objective — did the contract cover all necessary terms? Were boundaries precise? Were expectations mutual?  
**Infinite checkpoint:** Each contract is a standalone puzzle (2–8 minutes). Progress saves after every completed contract.

## 2. Catalyst Delivery

**Shadow provocation by design:**
- DA surfaces when player over-optimises for personal benefit in contract terms (measurable asymmetry in obligation distribution)
- DAll surfaces when player leaves relational terms vague or avoids specifying mutual obligations (measurable incompleteness)
- GA surfaces when player adds emotional/vulnerability clauses without structural support (measurable incoherence between affective language and contractual precision)
- GAll surfaces when contracts are technically perfect but contain no flexibility or renegotiation clauses (measurable rigidity index)

**Drive probing:** Agency measured by boundary precision. Communion measured by mutuality of terms. Eros measured by inclusion of growth/evolution clauses. Agape measured by care-for-other embedded in contract structure.

## 3. Game Design

**Mechanics:** Player receives a relational scenario (two parties, context, stakes) and must draft a contract using modular clause-blocks. Clauses cover: role allocation, expectation specificity, boundary conditions, renegotiation triggers, exit terms, and mutual-benefit balance.  
**Difficulty staircase:** Early contracts involve simple dyads with clear needs. Later contracts involve multi-party coordination, conflicting interests, ambiguous contexts, and time-pressure.  
**Feedback:** Objective scoring on 6 axes (completeness, precision, mutuality, flexibility, boundary-clarity, coherence). No subjective judgment — pure structural analysis.  
**Progression:** Contracts increase in relational complexity (stranger→colleague→friend→intimate→multi-party network). Shadow patterns emerge across 8+ contracts as systematic biases.

## 4. Item Pool

- 40 base scenarios (10 per relational tier: stranger/colleague/friend/intimate)
- 12 clause-block categories with 6–8 variants each
- 20 complication modifiers (power asymmetry, time pressure, cultural difference, prior betrayal)
- 8 multi-party scenarios (3–5 parties with competing interests)
- Adaptive difficulty: scenario complexity scales with demonstrated capacity

## 5. Technical Requirements

- Deterministic scoring engine: clause-completeness checker, mutuality calculator, rigidity index, asymmetry detector
- No LLM required — all evaluation is structural/mathematical
- Contract template system with drag-and-drop clause composition
- Shadow-signal extraction: per-contract drive scores derived from clause patterns
- Session state: contract-in-progress saves at any point
- Analytics: rolling 8-contract window for shadow-pattern detection
