# Interpersonal / Orange — Language-Reflective Game Concept

> **Axis:** Verbal articulation of relational life — how the player talks about relationships reveals depth vs. instrumentalisation.  **Why this axis for this module:** Orange contractual capacity lives in language — the ability to articulate expectations, name boundaries, and describe relational structures reveals whether the player has genuine contractual skill or shadow-driven distortions.

---

## 1. Game Identity

**Title:** Relational Lexicon  
**Core loop:** Player responds to prompts about relational situations using free-text. LLM evaluates the linguistic structure for contractual clarity, instrumentalisation markers, authenticity-bypass language, and fortress-rigidity patterns. The game is a reflective journal that scores itself.  
**Infinite checkpoint:** Each prompt is standalone (3–5 minutes per response). Progress saves on submission.

## 2. Catalyst Delivery

**Shadow provocation by design:**
- DA surfaces in language that frames others as resources ("leverage," "useful," "what they bring to the table") — detected via instrumentalisation lexicon analysis
- DAll surfaces in avoidant language ("I handle things myself," "relationships are distractions") — detected via relational-avoidance markers
- GA surfaces in premature-depth language ("soul connection," "radical honesty," "holding space") without accompanying contractual specificity — detected via authenticity-without-structure patterns
- GAll surfaces in exclusively professional/transactional framing with zero affective vocabulary — detected via emotional-absence markers

**Drive probing:** Agency in boundary-language clarity. Communion in mutuality-language presence. Eros in growth-oriented relational framing. Agape in care-language grounded in specifics rather than abstractions.

## 3. Game Design

**Mechanics:** Player receives relational prompts in three categories: (1) describe a relationship, (2) articulate an expectation to someone, (3) reflect on a relational conflict. Free-text responses are analysed by LLM rubric.  
**Difficulty staircase:** Early prompts are low-stakes (describe a good collaboration). Later prompts introduce emotional complexity (how would you tell someone they've crossed a boundary? how do you ask for what you need from someone you respect?).  
**Feedback:** Gentle reflective questions returned — never diagnostic labels. "You mentioned what they could offer you three times but didn't mention what you'd offer them — what do you notice about that?"  
**Progression:** Prompt complexity increases. Relational stakes deepen. Player's own prior responses are referenced to surface patterns across sessions.

## 4. Item Pool

- 60 prompts across 4 tiers (low-stakes → high-vulnerability)
- 15 prompts per tier covering: description, articulation, reflection, renegotiation
- LLM rubric dimensions: instrumentalisation index, avoidance index, bypass index, rigidity index, contractual clarity, mutuality, boundary precision, affective grounding
- Adaptive prompt selection based on detected shadow patterns
- 20 follow-up probes triggered by specific linguistic markers

## 5. Technical Requirements

- LLM integration for free-text analysis (rubric-based, not open-ended generation)
- Linguistic marker detection: instrumentalisation lexicon, avoidance patterns, bypass vocabulary, rigidity markers
- Longitudinal pattern tracking across 10+ sessions
- Privacy-first: responses stored locally, never transmitted without consent
- Shadow-signal extraction: per-response drive scores derived from linguistic analysis
- Reflective feedback generation: LLM produces non-diagnostic reflective questions
