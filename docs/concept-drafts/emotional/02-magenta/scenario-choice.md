# Emotional / Magenta — Scenario-Choice Game Concept

> **Axis:** The scenario-choice axis probes emotional intelligence through FEELING-INFORMED DECISIONS — can the player use emotional sensing to guide choices? At Magenta, this is: "This path feels scary. That path feels warm. Which do you choose?" Feelings as navigation data.
>
> **Why this axis for Emotional/Magenta:** Before emotions become decision-tools (Orange), they must first INFORM choices at the most basic level. At Magenta: "I go toward what feels good and away from what feels bad." This modality tests whether affect-sensing connects to action.

---

## 1. Game Identity

- **Title:** "The Feeling-Path"
- **Core mechanic:** The player faces choices where emotional atmosphere is the ONLY information. No logic, no rules — just: "This feels X, that feels Y. Which do you choose?" Can feelings guide navigation? Can the player use mood as a compass?
- **Duration:** 3-5 minutes per session (infinite checkpoints; fatigue-aware)
- **Internal progression:** The Warm Path → The Mood-Compass → The Feeling-Dilemma → The Mood-Trust → The Guided Heart

---

## 2. Catalyst Delivery

**Catalyst:** "Two paths. One feels warm. One feels cold. Which do you take? Why?" The contact boundary is: "Can your feelings guide your choices?"

**Unconscious response:**
- *Submergent:* How does the player use feelings in decisions? The Mood-Flooder is overwhelmed by both paths. The Affect-Denier can't sense either path's mood. The Premature Empath over-analyses both paths. The Feeling-Refuser senses but refuses to let feelings guide.
- *Emergent:* Can they sense the mood of each option AND use that sensing to choose?

**Integration path:** Rewards FEELING-GUIDED CHOOSING — using emotional sensing as navigation data. Not overwhelmed by options, not blind to their moods, not over-analysing, not refusing to let feelings matter.

**Successful integration:** The player uses emotional sensing to guide choices — feelings become functional navigation data.

---

## 3. Game Design

### Setup
The Feeling-Path: a choice-space where emotional atmosphere is the only navigation data. Paths with distinct moods — warm/cold, bright/dark, calm/agitated. No signs, no logic — just feeling. The player navigates by mood.

### Interaction
- **The Warm Path (1-5):** Two paths, one clearly warm, one clearly cold. Choose the warm one.
- **The Mood-Compass (5-15):** Multiple paths with different moods. Navigate toward a target feeling.
- **The Feeling-Dilemma (15-30):** Two paths, both attractive but different moods. Which feeling matters more?
- **The Mood-Trust (30-50):** Path that FEELS wrong but leads right (or vice versa). Can feelings be trusted?
- **The Guided Heart (50+):** Full feeling-guided navigation: sense → choose → trust → navigate.

### Feedback
- Feeling-guided choice → "Your feelings led you. See where you are? Your heart knew."
- Overwhelmed → "Quieter. Both are gentle. One is just a LITTLE warmer. Feel for the little difference."
- No sensing → "One is warm. Really. Feel it. The warmth. It's there. Choose the warm one."
- Over-analysis → "Stop thinking. Feel. Quick. Which one? Go. Your gut knows."
- Refuses feelings → "Try it. Just once. Let the feeling choose. See what happens."

### Difficulty Adaptation
- Mood difference between options: large → moderate → subtle
- Number of options: 2 → 3 → 4
- Mood valence: clear (warm=good) → ambiguous (both good, different) → paradoxical
- Time pressure: none → moderate (prevents over-analysis)
- Outcome feedback: immediate → delayed

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The Warm Path | 1-5 | Clear warm vs. cold; obvious choice |
| The Mood-Compass | 5-15 | Navigate toward target feeling |
| The Feeling-Dilemma | 15-30 | Both attractive; which feeling matters more? |
| The Mood-Trust | 30-50 | Feelings as reliable navigation data |
| The Guided Heart | 50+ | Full feeling-guided navigation |

---

## 4. Item Pool

### Item types
- **Clear-contrast items:** Obvious mood differences between paths
- **Navigation items:** Multiple paths toward a target feeling
- **Dilemma items:** Two attractive options with different moods
- **Trust items:** Feeling-guided choices with delayed outcome feedback
- **Ambiguity items:** Subtle mood differences requiring calibrated sensing

### Minimum pool size
- 25+ clear-contrast, 20+ navigation, 15+ dilemma, 15+ trust, 10+ ambiguity

### Drive/shadow mapping
- Overwhelmed/intensity-seeking → dark-addiction; no sensing/random → dark-allergy
- Over-analysis/paralysis → golden-addiction; sensing without using → golden-allergy

---

## 5. Technical Requirements

### Input types
- Tap-to-select (path choice); hold-to-sense (linger on option to feel it); swipe (navigate)

### Timing requirements
- Choice latency tracked; sensing-duration per option; no punishing time pressure but latency informative

### NPC/AI requirements
- Path visualization with distinct emotional atmospheres (colour, sound, movement)
- Mood-contrast system (ensures options are distinguishable)
- Optional: companion who models feeling-guided choosing

### LLM requirements
- **Medium:** Scenario generation, dilemma construction, outcome narratives. Core choice-mood alignment partially algorithmic.

### State persistence
- Feeling-choice alignment rates; sensing accuracy at choice-points; choice latencies; feeling-trust indicators; dilemma resolution quality; overwhelm indicators; no-sensing indicators; over-analysis indicators; feeling-rejection indicators; drive/shadow signals; fatigue state; checkpoint position
