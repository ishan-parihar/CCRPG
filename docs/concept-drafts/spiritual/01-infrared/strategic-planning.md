# Spiritual × Infrared — Strategic-Planning Game

## 1. Core Concept

**Title:** Approach, Then Pause

The simplest possible wonder-strategy: move toward the vast, then stop. A 2-step engagement pattern that is the seed of all later contemplative practice. The organism must PLAN its encounter with enormity — not stumble into it (impulsive) and not avoid it (numb), but deliberately approach and then deliberately pause to receive.

The game presents vast-sources at varying distances. The player must choose an approach-path and a pause-point — too close and they're overwhelmed (fixation); too far and they miss it (numbness); approaching without pausing is premature; pausing without approaching is fortress.

## 2. Mechanical Specification

**Input:** Two-phase input per trial: (1) drag/swipe to set approach-distance, (2) tap to set pause-duration. Simple spatial planning.

**Stimuli:** Vast-sources rendered as luminous phenomena at varying distances — a glow on the horizon, a pool of starlight, a heat-shimmer. Each has an optimal engagement zone (not too close, not too far) and an optimal dwell-time.

**Metrics captured:**
- Approach distance chosen: too close (fixation-risk), too far (numbness-risk), optimal (healthy engagement)
- Pause duration chosen: too long (fixation), too short (fortress), absent (premature), optimal (integration)
- Adaptation across trials: does the player learn from feedback (the felt-sense of "right distance")?
- Sequence planning: when multiple vast-sources appear, can the player sequence approach-pause-return-approach?
- Return quality: after pause, does the player return to safety smoothly or get stuck?

**Progression:** Early trials have obvious optimal zones (dramatic vastness, clear feedback). Later trials have ambiguous zones — the player must develop felt-sense for "how close is close enough" with subtle phenomena.

## 3. Shadow Diagnostics

| Shadow | Behavioural Signal |
|---|---|
| DA (Awe-Fixation) | Consistently chooses closest approach + longest pause; cannot set boundaries with the vast |
| DAll (Awe-Numbness) | Consistently chooses farthest approach + shortest pause; minimal engagement with vast-sources |
| GA (Premature Animism) | Approaches without pausing; rushes through engagement; no receptive stillness |
| GAll (Awe Fortress) | Sets appropriate approach but minimal/zero pause; reaches the vast then immediately retreats |

## 4. Catalyst → Experience → Integration

**Catalyst:** The vast-source at a distance — requiring deliberate approach rather than passive reception. The organism must CHOOSE to engage with enormity.

**Experience:** The felt-sense of "right distance" — not too close (overwhelm), not too far (disconnection). This is the proto-contemplative skill: knowing how to be with the numinous without being consumed or dismissive.

**Integration:** The return-to-safety after each approach-pause cycle. Integration = the organism can plan engagement with wonder, execute it, and return. The full cycle: safety → approach → pause → receive → return → safety. This 2-step plan is the seed of all later spiritual practice.

**Healing vector (bottom-up):** For awe-numbness — optimal zones are made more obvious, approach is rewarded with warmth; for awe-fixation — return-to-safety is made rewarding, boundaries are scaffolded.

**Evolution vector (top-down):** For premature animism — the game requires pause before any engagement registers; for awe-fortress — pause-duration feedback shows that lingering is safe, nothing bad happens from staying.

## 5. Infinite Checkpoint Structure

Each session = 6–12 approach-pause trials (4–8 minutes). Each completed return-to-safety is a checkpoint. The player's "engagement profile" (preferred distances, pause-durations, adaptation rate) evolves across sessions. Theta-decay: the planning capacity must be re-demonstrated; old optimal-zone knowledge doesn't persist without practice.
