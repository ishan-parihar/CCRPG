# Spiritual × Infrared — Language-Reflective Game

## 1. Core Concept

**Title:** The Breath Before Words

At Infrared, there is no language for the sacred. But there IS pre-verbal expression of wonder: the caught breath, the involuntary gasp, the silence that follows being struck. This game measures the organism's capacity to express awe through proto-vocalisation — sounds that are not yet words but carry the weight of encounter with the vast.

The player's avatar sits before something enormous. The game listens for breath-sounds, silence-duration, and proto-reverence vocalisations via rhythmic tap-patterns that simulate breath.

## 2. Mechanical Specification

**Input:** Rhythmic tap-patterns representing breath — short tap = inhale, hold = held breath, release = exhale. Microphone mode optional for devices that support it.

**Stimuli:** Slow-building vast-reveals (aurora emerging, ocean becoming visible as eyes adjust to dark, embers rising into a star-field). Each builds over 10–20 seconds.

**Metrics captured:**
- Breath-catch latency: how quickly breath-pattern shifts when the vast appears
- Silence duration: how long the player holds stillness after being struck (proto-reverence)
- Gasp-signature: sudden sharp input followed by extended hold (genuine awe-response)
- Resumption quality: how breath returns after the wonder-moment — smooth (integrated) vs. jagged (fixated) vs. immediate (suppressed)
- Vocalisation-without-stimulus: expressing wonder at nothing (premature animism signal)

**Progression:** Early stimuli are dramatic and unmissable. Later stimuli are subtle — a single star appearing, a slight warmth-shift. Can the organism still find the breath-catch for quiet enormity?

## 3. Shadow Diagnostics

| Shadow | Behavioural Signal |
|---|---|
| DA (Awe-Fixation) | Silence extends indefinitely; breath never fully resumes; player cannot return to ordinary rhythm |
| DAll (Awe-Numbness) | No breath-pattern change regardless of stimulus; flat rhythmic profile throughout |
| GA (Premature Animism) | Gasp-signatures at non-vast moments; constant proto-reverence without discrimination |
| GAll (Awe Fortress) | Brief breath-catch immediately followed by forced normalisation; deliberate rhythm-override |

## 4. Catalyst → Experience → Integration

**Catalyst:** The slow-building vast-reveal — not sudden, but emerging. The organism must notice the sacred arriving, not just react to shock.

**Experience:** The breath responds before the mind does. The game captures this pre-cognitive spiritual response — the body's first language for the numinous.

**Integration:** Each vast-reveal is followed by a "return-breath" phase — the player is guided (through ambient audio pacing) back to ordinary rhythm. Integration = the breath can hold the memory of wonder without being trapped in it.

**Healing vector (bottom-up):** For awe-numbness — breath-pacing guides gradually deepen, teaching the body to respond; for awe-fixation — return-breath phases provide gentle scaffolding back to ordinary.

**Evolution vector (top-down):** For premature animism — the game only acknowledges genuine breath-catch (discriminated response); for awe-fortress — the return-breath phase is extended, allowing wonder to linger without demanding interpretation.

## 5. Infinite Checkpoint Structure

Each session = one breath-cycle sequence (4–10 minutes). The player can pause at any return-breath moment. Progress is the evolving breath-profile over time — a living record of the organism's relationship to wonder. Theta-decay: if the player doesn't practice, the breath-catch capacity score decays, requiring re-demonstration that wonder still lives in the body.
