# Spiritual / Magenta — Scenario-Choice Game Concept

> **Axis:** The scenario-choice axis probes spiritual intelligence through SACRED DECISION — what does the player DO when the sacred and the profane conflict? At Magenta, this is: "The spirits say one thing. The easy path says another. Which do you follow? What matters most?"
>
> **Why this axis for Spiritual/Magenta:** Before moral reasoning about values (Amber+), sacred decision is FELT — "the spirits want me to go this way." This modality tests whether the player can orient behaviour around the sacred when it conflicts with convenience, safety, or desire.

---

## 1. Game Identity

- **Title:** "The Sacred Path"
- **Core mechanic:** The player faces choices where the sacred path and the easy/safe/powerful path diverge. Not moral dilemmas (that's the Moral line) but SACRED dilemmas — "the spirits say go left, but right is easier/safer/more rewarding. Which way?" Tests value-from-sacred: does the numinous actually orient behaviour?
- **Duration:** 2-4 minutes per session (infinite checkpoints; fatigue-aware)
- **Internal progression:** The First Fork → The Hard Sacred → The Hidden Path → The Costly Sacred → The Living Follower

---

## 2. Catalyst Delivery

**Catalyst:** "Two paths. One glows — the sacred way. One is easy — the ordinary way. The sacred path is harder. Which do you choose? What matters more — ease or the glow?" The contact boundary is: "Does the sacred orient your behaviour?"

**Unconscious response:**
- *Submergent:* How does the player choose? The Spirit-Addict ALWAYS chooses sacred ("The spirits! Always the spirits!") — compulsive, not genuine. The Spirit-Denier ALWAYS chooses easy ("Why would I go the hard way? There's nothing there"). The Premature Priest chooses sacred ONLY when it gives power ("The sacred path — if it makes me stronger"). The Sacred-Refuser approaches sacred path then retreats ("I was going to but… the other way is fine").
- *Emergent:* Can they choose the sacred path GENUINELY — not compulsively, not for power, not avoidantly?

**Integration path:** Rewards GENUINE SACRED ORIENTATION — choosing the numinous path because it matters, not because of compulsion, power, or performance. Authentic value-from-sacred.

**Successful integration:** The player can orient behaviour around the sacred — the decisional foundation of spiritual intelligence.

---

## 3. Game Design

### Setup
The Sacred Path: a choice-space where paths diverge. One path glows (sacred); one is ordinary. The sacred path is harder/longer/costlier but leads to numinous content. The ordinary path is easy but flat. The player chooses. The aesthetic: Magenta-stage spirit-crossroads — forking paths in a magical forest, one glowing faintly.

### Interaction
- **The First Fork (1-5):** Simple binary: sacred path (slightly harder) vs. ordinary path (easy). Clear glow.
- **The Hard Sacred (5-15):** Sacred path is SIGNIFICANTLY harder. Tests genuine commitment.
- **The Hidden Path (15-30):** Sacred path is not obviously marked. Must SENSE which is sacred.
- **The Costly Sacred (30-50):** Sacred path requires SACRIFICE (give up something to follow).
- **The Living Follower (50+):** Full sacred orientation: discerning + committed + sacrificial + spontaneous.

### Feedback
- Genuine sacred choice → "You followed the glow. Even though it was harder. The sacred honours you."
- Compulsive sacred → "Wait. Is this path REALLY sacred? Or are you just always choosing the hard way? Think."
- Always ordinary → "The glow is there. Can you see it? Just this once. Try the glowing path."
- Transactional → "Not for reward. For the glow itself. Is the sacred worth following without a prize?"
- Approach-withdrawal → "You felt it! The pull. Just one step. You don't have to go all the way."

### Difficulty Adaptation
- Cost differential: slight (sacred slightly harder) → significant → sacrificial
- Clarity: obvious glow → subtle glow → hidden sacred
- Frequency: occasional forks → frequent → constant orientation required
- Social pressure: solo → companion disagrees → group pressure against sacred
- Ambiguity: clear sacred/ordinary → ambiguous → sacred-in-ordinary

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The First Fork | 1-5 | Simple sacred vs. ordinary (low cost) |
| The Hard Sacred | 5-15 | Significant cost to sacred path |
| The Hidden Path | 15-30 | Sacred path not obviously marked |
| The Costly Sacred | 30-50 | Sacred path requires sacrifice |
| The Living Follower | 50+ | Full sacred orientation integration |

## 4. Item Pool Specification

### Item types
- **Low-cost forks:** Sacred slightly harder (entry-level)
- **High-cost forks:** Sacred significantly harder (commitment test)
- **Hidden forks:** Sacred path not obviously marked (detection + choice)
- **Sacrificial forks:** Must give up something to follow sacred (sacrifice test)
- **Ambiguous forks:** Unclear which is sacred (discernment test)

### Minimum pool size
- 25+ low-cost, 20+ high-cost, 15+ hidden, 10+ sacrificial, 10+ ambiguous

### Drive/shadow mapping
- Always sacred (compulsive) → dark-addiction; always ordinary → dark-allergy
- Sacred only when rewarding → golden-addiction; approach-withdrawal → golden-allergy

---

## 5. Technical Requirements

### Input types
- Tap (choose path); swipe (direction); hold (commit to choice under pressure)

### Timing requirements
- Decision latency tracked (hesitation patterns); no time pressure; deliberation quality noted

### NPC/AI requirements
- Fork generation system (sacred/ordinary paths with controlled cost differential)
- Sacred-marking system (glow intensity, subtlety)
- Cost system (what the sacred path costs)
- Difficulty adaptation (cost, clarity, frequency, social pressure)

### LLM requirements
- **Medium:** Choice-pattern analysis; compulsion detection; transactional-vs-genuine assessment. Core path-choice tracking algorithmic.

### State persistence
- Choice history; sacred orientation rate; discernment quality; commitment level; consistency metrics; spontaneity indicators; compulsion indicators; blindness indicators; transactional indicators; avoidance indicators; drive/shadow signals; fatigue state; checkpoint position
