# Intrapersonal / Magenta — Deterministic Game Concept

> **Axis:** The deterministic axis probes intrapersonal intelligence through OBJECTIVE SELF-RECOGNITION — can the player identify their own self-image when presented among others? At Magenta, this is: "Which one is YOU? Can you find yourself in the mirror-pool?" Not reflection — RECOGNITION.
>
> **Why this axis for Intrapersonal/Magenta:** Before reflective self-knowledge (Red+), self-knowledge is RECOGNITION — "that's me!" The mirror-stage. This modality tests whether the player can identify their own magical self-image objectively.

---

## 1. Game Identity

- **Title:** "The Mirror-Pool"
- **Core mechanic:** The player's magical self-image is reflected among distortions, other-images, and phantoms. Can they find THEMSELVES? Not "who do you want to be?" but "which one IS you?" Objective self-recognition at the magical level.
- **Duration:** 2-4 minutes per session (infinite checkpoints; fatigue-aware)
- **Internal progression:** The First Reflection → The Many Faces → The Changing Self → The Hidden Self → The Living Mirror

---

## 2. Catalyst Delivery

**Catalyst:** "Look into the mirror-pool. Many images appear. Which one is YOU? Not which one do you WANT to be — which one IS you? Find yourself." The contact boundary is: "Can you recognise your own self-image?"

**Unconscious response:**
- *Submergent:* How does the player respond to self-recognition tasks? The Fantasy-Prisoner always picks the GRANDEST image ("that's me — the biggest, brightest one"). The Self-Stranger cannot pick ANY ("I don't know which one is me"). The Premature Ego picks the STRONGEST ("the powerful one"). The Identity-Refuser approaches then retreats ("maybe that one… no, I don't know").
- *Emergent:* Can they recognise their actual self-image — neither inflated nor absent?

**Integration path:** Rewards ACCURATE SELF-RECOGNITION — identifying the actual self-image among alternatives. Not the grandest, not blank, not the most powerful, not avoidant.

**Successful integration:** The player reliably recognises their own magical self-image — the foundation of self-knowledge.

---

## 3. Game Design

### Setup
The Mirror-Pool: a magical reflecting surface. Images appear — some are the player's self-image, some are others, some are distortions. The player identifies which is THEM. The aesthetic: Magenta-stage mirror-pool — shimmering water showing faces/figures, one of which is the player's magical self.

### Interaction
- **The First Reflection (1-5):** One image clearly "you" among clearly "not-you." Binary recognition.
- **The Many Faces (5-15):** Multiple similar images; find the one that's actually you.
- **The Changing Self (15-30):** Self-image changes slightly; recognise the changed self as still you.
- **The Hidden Self (30-50):** Self-image partially obscured; recognise from fragments.
- **The Living Mirror (50+):** Full self-recognition: accurate + flexible + constant + felt.

### Feedback
- Accurate recognition → "Yes! That's you. You found yourself. The mirror knows you."
- Inflated → "Not the biggest. The real one. Smaller. Quieter. But truly you."
- Blank → "Look again. One of them is different. That difference is YOU. See it?"
- Power-based → "Not the strongest. The one that dreams. The playful one. Also you."
- Avoidant → "Quick! Point! That one? Yes! That's you. See? Not so scary."

### Difficulty Adaptation
- Distinction clarity: obvious → moderate → subtle
- Number of alternatives: 2 → 4 → 8
- Self-image stability: static → changing → fragmentary
- Distractor similarity: very different → similar → near-identical
- Context: familiar setting → novel setting → ambiguous setting

### Internal Progression
| Phase | Checkpoint range | What changes |
|---|---|---|
| The First Reflection | 1-5 | Binary self/not-self recognition |
| The Many Faces | 5-15 | Multiple alternatives; find actual self |
| The Changing Self | 15-30 | Recognise changed self as still self |
| The Hidden Self | 30-50 | Recognise self from fragments |
| The Living Mirror | 50+ | Full self-recognition integration |

---

## 4. Item Pool Specification

### Item types
- **Clear self-images:** Obviously the player's magical self
- **Clear others:** Obviously not the player
- **Similar others:** Look like the player but aren't
- **Changed self:** The player's self-image slightly altered
- **Fragmented self:** Partial self-images requiring completion

### Minimum pool size
- 25+ clear self, 30+ clear others, 20+ similar others, 15+ changed self, 10+ fragmented

### Drive/shadow mapping
- Always picks grandest → dark-addiction; cannot pick → dark-allergy
- Picks most powerful → golden-addiction; approach-withdrawal → golden-allergy

---

## 5. Technical Requirements

### Input types
- Tap-to-select (identify self-image); swipe (reject non-self); hold (confirm selection)

### Timing requirements
- Selection latency tracked; no time pressure; hesitation patterns diagnostic

### NPC/AI requirements
- Self-image generation system (player's magical self-image)
- Distractor generation (similar-but-different images)
- Difficulty adaptation (distinction clarity, number, similarity)
- Change system (self-image evolution tracking)

### LLM requirements
- **Low:** Primarily algorithmic. LLM for self-image generation and edge-case assessment only.

### State persistence
- Recognition accuracy rates; discrimination scores; constancy quality; latency patterns; confidence metrics; inflation indicators; absence indicators; power-selection indicators; avoidance indicators; drive/shadow signals; fatigue state; checkpoint position
