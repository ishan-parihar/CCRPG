# Intrapersonal × Infrared — Strategic-Planning

## 1. Core Mechanic

**Boundary-Sequencing.** The simplest possible planning at Infrared: detect boundary, then respond to boundary. Two-step self-other sequences. The player must first IDENTIFY whether a stimulus is self or other, THEN execute the appropriate response. The 'strategy' is the gap between detection and action — the proto-planning seed.

### 1.1 Mechanic Design

- Stimuli arrive at the avatar's boundary. Step 1: classify (self/other). Step 2: respond (self = absorb, other = deflect)
- The two steps must be executed in order — classification before response
- Premature response (acting before classifying) is penalised
- Correct sequencing: detect → pause → classify → respond

### 1.2 Difficulty Staircase

- Level 1: single stimulus, long pause window between detection and response
- Level 2: single stimulus, shorter pause window
- Level 3: two stimuli in rapid succession — must sequence both correctly
- Level 4: interleaved self/other stimuli requiring alternating response-sequences

## 2. Shadow Probes

| Shadow | Probe Pattern | Behavioural Signal |
|--------|--------------|-------------------|
| DA (Boundary-Fixation) | Always deflects first, classifies second — boundary-defence overrides sequence | Deflect-before-classify rate > 60% |
| DAll (Boundary-Dissolution) | Always absorbs first — no deflection in repertoire | Absorb-before-classify rate > 60% |
| GA (Premature Self-Image) | Skips classification entirely — responds based on 'intuition' without detection step | Classification-skip rate > 50% |
| GAll (Boundary Fortress) | Classifies correctly but freezes before response — cannot act on boundary-knowledge | Response-omission rate > 40% after correct classification |

## 3. Catalyst → Experience → Integration

### 3.1 Catalyst

Stimuli that arrive faster than the player's current sequence-speed, forcing the boundary between reactive (shadow) and sequential (healthy) processing.

### 3.2 Experience

Correct sequence (detect→classify→respond): smooth animation, boundary pulses with competence. Broken sequence: jarring interruption, boundary stutters. The felt-sense of 'I knew what it was before I acted.'

### 3.3 Integration

Successful sequencing builds 'boundary-intelligence' — the avatar begins to anticipate stimuli type before contact. Shadow-mode: the player's sequence-break pattern manifests as a creature that acts without knowing (DA/DAll) or knows without acting (GAll).

## 4. Progression

- **Diagnosis (trials 1–15):** Baseline sequence-integrity — can the player maintain detect→classify→respond order?
- **Healing (trials 16–40):** Target sequence-breaks. If DA, slow the deflect-impulse with forced pause. If GAll, reduce response-threshold with gentle action-prompts.
- **Evolution (trials 41+):** Extend to 3-step sequences (detect→classify→plan→respond), seeding Magenta's more complex self-other planning

## 5. Scoring

- **Primary metric:** sequence-integrity rate (correct order maintained across trials)
- **Speed metric:** sequence-completion time (faster = more integrated, but not premature)
- **Error-type metric:** which step breaks first (classification errors vs. response errors vs. order errors)
- **Drive-health:** fast, accurate, correctly-ordered sequences = healthy boundary-planning
- **Shadow-drag:** sequence-break rate + specific break-pattern severity, weighted 0.18
- **Cross-line bonus:** +0.10 when cognitive-line inhibitory-control is also healthy (impulse-management supports sequencing)
